## Projetos em Destaque

### 🎵 Music Dashboard
🔗 [music-dashboard](https://github.com/FilipeMadeira13/music-dashboard)

Dashboard interativo para análise de dados musicais utilizando a API do Last.fm.

- Consumo de API externa com tratamento e normalização de dados
- Métricas de engajamento (plays por listener, plays por faixa)
- Múltiplos dashboards: Top Albums, Top Tracks e Similar Artists
- Cache inteligente para otimização de performance
- Exportação de dados para CSV

**Stack:** Python · Streamlit · Pandas · Plotly · API REST

### 🤖 Churn Prediction  
🔗 [churn-prediction](https://github.com/FilipeMadeira13/churn_prediction)

Projeto de análise e modelagem para previsão de churn de clientes usando aprendizado de máquina em Python.

- Carregar e limpar os dados de churn  
- Codificar variáveis categóricas  
- Treinar e avaliar modelos de classificação
- Aplicar validação cruzada e técnicas de balanceamento de classes

### 📉 Customer Churn Analysis
🔗 [churn-analysis-project](https://github.com/FilipeMadeira13/churn-analysis-project)

Análise dos fatores que levam clientes de uma empresa de telecomunicações a cancelar seus serviços.

- Pipeline completo: ingestão → limpeza → armazenamento em SQLite → análise

- Identificação de perfis de alto risco e recomendações de retenção

**Stack:** Python · SQL · SQLite · Pandas · Jupyter
